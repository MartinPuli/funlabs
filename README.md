# FUNLABS

**Give your agent human evidence.**

FUNLABS is a proposed harness for agents building interactive experiences. It connects paid human playtests, evidence-backed agent work, and version comparisons so creators can decide what to change and what to preserve.

Start with the [product and implementation plan](FUNLABS.md), written in Spanish. It includes the pitch, human and agent bounties, data contracts, design system, sponsor integrations, MVP, and judging/demo plan.

## Current status

Planning only. This repository contains the product specification; the application and integrations are not implemented. No demo video has been created. Payment examples in the plan are for test mode.

## First milestone

Capture one real playtest of our own web game, produce a reviewable finding with Gemini, and link it to its original recording. Then complete the cycle through an agent change and a human comparison.
